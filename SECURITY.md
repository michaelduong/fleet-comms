# Security policy

## Report a vulnerability privately

Please use [GitHub private vulnerability reporting](https://github.com/michaelduong/fleet-comms/security/advisories/new)
if it is enabled for this repository. Include affected versions, reproduction steps, impact, and a minimal
example using synthetic data. Do not include credentials, login stores, personal transcripts, or fleet records.

If private reporting is unavailable, open a public issue asking a maintainer for a private reporting channel.
Do not disclose vulnerability details in that issue. Wait for a private channel before sharing reproduction details.

## Supported versions

Security fixes target the latest source on the default branch. There is no commitment to backport fixes
to older releases. Please reproduce against current source when practical.

## Scope

Reports about the app, its local file access, credential handling, model downloads, or integrations are welcome.
Report vulnerabilities in upstream libraries and model tooling to their respective maintainers as well.
